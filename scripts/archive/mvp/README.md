# Archived MVP scripts

These files are the earlier hand-written OPD MVP path. They are kept for reference only and are not the current training workflow.

Use `scripts/trl_opd/` for formal TRL OPD training.

Archived files:

- `setup_trl_env.sh`: legacy environment setup for the MVP dependencies.
- `train_trl_opd_mvp.py`: explicit single-sample MVP training loop.
- `run_trl_opd_mvp.sh`: launcher for the MVP loop.
- `run_trl_opd_full_gsm8k_2gpu.sh`: old full-GSM8K MVP launcher.
